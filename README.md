## AI-агент: Новости

Агент принимает запрос пользователя, при необходимости вызывает NewsAPI, обрабатывает результат и формирует ответ на русском языке.

**Инструмент**  
- `get_news(topic)` – получает 5 последних новостей по теме через [NewsAPI](https://newsapi.org).

**Как запустить**

pip install -r requirements.txt
python main.py
